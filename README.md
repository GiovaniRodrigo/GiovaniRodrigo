## 📦 Projetos Principais

### 🐳 Gerador de Dockerfile PHP com Python
**[gerador_dockefile_php](https://github.com/GiovaniRodrigo/gerador_dockefile_php)**

Ferramenta interativa em Python para gerar Dockerfiles customizados para ambientes PHP.

- **Funcionalidades**:
  - Suporte para múltiplas versões do PHP (5.6 até 8.2)
  - Seleção interativa de extensões PHP
  - Interface em menu para escolha de versão
  - Disponível como imagem Docker: `giovanii/gerador_dockerfile`

- **Tecnologias**: Python, Docker, Shell
- **Como usar**:
  ```bash
  docker run -it -v "$(pwd)/Dockerfiles:/usr/src/app/Dockerfiles" giovanii/gerador_dockerfile
  ```
